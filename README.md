# Vehicle Rental Indonesia — website foundation

## Stack
- Next.js App Router, React 19 and TypeScript
- Custom CSS design system with lightweight native interactions

## Run locally
Install dependencies with npm install, then run npm run dev.

## First implementation
- Premium editorial homepage direction and responsive navigation
- Cinematic hero with restrained motion and subtle background drift
- Vehicle collection with category filtering
- Responsive vehicle cards and enquiry entry points
- Scroll reveal interactions with reduced-motion support

## Before production
- Replace the provisional MOBILITY INDONESIA wordmark with the approved company brand.
- Replace illustrative vehicle photography and sample fleet entries with approved assets and verified fleet data.
- Configure real contact channels and inquiry delivery; the current contact CTA is intentionally marked as a placeholder.
